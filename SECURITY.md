# Security Policy

## Reporting a Vulnerability

Please do not report suspected security vulnerabilities
through public GitHub issues.

Use GitHub's private vulnerability reporting feature
when available.

Reports should include:

- A description of the suspected vulnerability
- Steps to reproduce the issue
- Affected versions or components
- Potential security impact
- Any suggested mitigation

Please avoid publicly disclosing vulnerability details
until the issue has been reviewed.

## Supported Versions

Until formal releases and a support policy are established,
the latest development version is the primary version
under active maintenance.

## Security Considerations

The IT Toolkit is designed for local troubleshooting
and offline operation.

Users should:

- Obtain runtime packages from trusted sources.
- Review diagnostic reports before sharing them.
- Protect local configuration and operational data.
- Avoid committing credentials or private infrastructure
  information to the repository.
